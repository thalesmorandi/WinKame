# WinKame name and logo

The WinKame code is open source under the GNU GPL v3 (see `LICENSE` and `NOTICE`). The name and the logo are not covered by that license.

"WinKame", the WinKame logo and "morandi.cloud" identify the official product created by Thales de Oliveira Morandi and published by morandi.cloud.

## You can, without asking

- Say that your project is "based on WinKame" or "a fork of WinKame", with the attribution required in `NOTICE`.
- Use the name to talk about WinKame: articles, reviews, tutorials, videos, package listings that install the official release.
- Build and run unmodified copies of the official source code for yourself.

## Please ask first

- Distributing a modified version under the name WinKame, or with the WinKame logo.
- Using the name or logo in another product's name, domain, app store listing or marketing.
- Anything that could make people think your project is the official WinKame or is endorsed by morandi.cloud.

A modified version should use its own name and icon. Contact: https://morandi.cloud
